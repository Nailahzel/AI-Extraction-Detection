RISK POINTS
A

Adaptive baselines

After 16 trusted intervals, a bounded median estimates each key’s usual query rate. Cold-start keys use 36 queries/minute.

B

Limited data retention

Rolling observations are capped at 256 per key. The SQLite log retains approximately 5,000 metadata records and no raw prompts.

C

Known limitations

Lexical similarity is not semantic understanding. Shared benign automation can resemble a campaign; distributed non-overlapping probes can evade it.

How to run the demo

Follow one key from its first requests to the alert and response.

  1. Start with normal traffic.Run the live demo. Two normal clients start receiving predictions.
  2. Watch the extraction probes.At five seconds, diverse extraction probes begin. Watch risk rise and requests receive HTTP 429.
  3. Inspect the alert.Open the suspicious API key. Show the exact signal contributions and normal clients still receiving answers.
  4. Try several keys.Reset in Attack lab, then run Coordinated campaign. Open Campaigns to show shared evidence across keys.
  5. Check the results.Open Validation. Explain synthetic regression results, reused test sessions, slow-attack latency, and limitations.
